Q1: How much does a cheap VPS actually cost to start?

Less than most people expect. In our 2026-09-30 snapshot, entry tiers at several tracked providers start at $2.00/month: RackNerd ($2.00), IONOS ($2.00), Virmach ($2.00) and BuyVM ($2.00) all have starting prices at that level, with InterServer at $3.00/month. Annual billing usually drops the effective monthly figure further — this is how "from $1.25/month" pricing you see in deal threads is typically constructed.

Budget honestly, though: the sticker price is the starting price, not necessarily the forever price. Read Q6 before you pay.

Q2: Which plan should a first-timer actually pick?

Buy one tier above the absolute minimum. The cheapest slot on a page is usually sized for "one tiny thing" (a personal VPN endpoint, a static site, a bot) — and beginners almost always run two things on their first box. The sweet spot for a first server is typically 2 GB RAM: enough for a small WordPress site or a project with a database, still squarely in cheap territory.

If you want the full sizing math — what 1 vCPU and 2 GB RAM actually run — see our VPS sizing guide. And ignore the upsells at checkout: managed backups, control panels and premium support are optional add-ons, not requirements.

Q3: Which datacenter location should I choose?

The one closest to whoever will use the server. Distance is latency: a visitor in Berlin reaching a server in Frankfurt gets ~10 ms; reaching Los Angeles gets ~150 ms. There is no "best" location in the abstract.

At checkout, providers list their available cities and you pick one — it is not assigned randomly. Two traps to know about: (1) some budget providers only offer IPv6 in a handful of locations, so if you need IPv4 everywhere, confirm it for your chosen city; (2) switching datacenters later is usually not an upgrade — it means ordering a new box and moving your data yourself. So spend the extra minute choosing the right city now.

Q4: What happens between clicking "order" and my first login?

The real, unglamorous sequence:

  1. Checkout. You pick the plan, location, operating system (choose Ubuntu 22.04 or 24.04 LTS if unsure) and billing cycle. You will be asked for an email address that can actually receive mail — your root password and server IP arrive there.
  2. Payment and verification. Card or PayPal. Some budget providers run a fraud check on the first order; a short delay or a support email asking for confirmation is normal, not a scam.
  3. Provisioning. Anywhere from 5 minutes (automated clouds) to a few hours (manual-review budget hosts). You will get a "your server is ready" email with an IP address, a username (usually root) and a password.
  4. First login. That email is your starting point for Q5.

Q5: How do I connect to my new VPS for the first time?

Over SSH — the encrypted remote shell that is the front door of every Linux VPS. On macOS or Linux, open a terminal and type: 

ssh root@YOUR_SERVER_IP

You will be prompted for the password from the setup email (paste it; the terminal shows nothing while you type — that is normal). On Windows, open Windows Terminal or PowerShell and run the same command, or use PuTTY if you prefer a graphical tool.

Accept the host-key fingerprint when asked. Then change the root password immediately: 

passwd

Q6: What should I do in the first 15 minutes on a fresh box?

Run this checklist before you install anything else. These are the steps that separate a server that survives from one that gets compromised in its first week:

  1. Update everything: apt update && apt upgrade -y
  2. Create a non-root user with sudo access and log in as them from now on (adduser deploy, then usermod -aG sudo deploy).
  3. Switch to SSH key login and disable password authentication. Copy your public key to ~/.ssh/authorized_keys for the new user, then set PasswordAuthentication no in /etc/ssh/sshd_config and restart SSH.
  4. Turn on the firewall: ufw allow OpenSSH, then ufw enable. Only open the ports you actually need.
  5. Set up backups you control. Cheap plans usually do not include automated backups, or charge extra for them. A daily off-provider backup (object storage, or even a second cheap box) is non-negotiable for anything you care about.

Q7: Will the price jump on renewal — and can I upgrade later without reinstalling?

The renewal question is the one deal pages least want to answer. The pattern in the budget VPS market: annual specials are frequently recurring at the same price (you pay the same next year), while "first-year 80% off" monthly plans from the big hosts typically jump 2–3× on renewal. Neither behavior is universal — the only reliable source is the provider's terms page or cart, which shows "renewal price" separately from the promo price. If a page shows no renewal price, treat that as a question to ask support before paying.

As for upgrades: most KVM providers upgrade you in place — you pick a bigger tier in the control panel, the server reboots, and the new RAM/CPU take effect with no reinstall and no data loss. But moving between locations is a different story: that usually means a fresh server and a manual migration (see Q3). So plan the location carefully and the plan size loosely.

Do I need managed VPS as a beginner?

Honest answer: managed hosting buys you someone to call when things break. Unmanaged cheap VPS buys you full control and full responsibility — security updates, failures and configuration are yours (see the checklist in Q6). If your project is a hobby or a learning box, unmanaged is fine and much cheaper. If it is a business that loses money when the site is down, either buy managed or make sure you know what Q6 means line by line.
